# Responsible use

CareerOS is built to make each application better, not to send more of them.
These limits are part of the design, not settings to switch off.

**Truth.** Everything it writes is traceable to your Career Brain, and the
claims gate blocks what isn't. Recruiters cross-check resumes against LinkedIn
and probe them in phone screens; a single invented claim costs more than any
application gains.

**Platforms.** It doesn't automate LinkedIn or Indeed (both prohibit it, and
accounts get restricted), doesn't create accounts, enter passwords, or solve
captchas, and polls public feeds politely. Respect each site's terms; if a site
forbids automation, apply there by hand.

**People.** Outreach is drafted for you to send. No bulk messages, no scraped
contact lists, no guessed email addresses, no impersonation.

**Your data.** Your brain, profile, packages and receipts live in git-ignored
files on your machine (or in an artifact database only you can read). Agents
send models only what a task needs. Don't put government ID numbers, bank
details or passwords in any file this project reads.

**Volume.** Keep a daily cap. Fewer, faster, better-targeted applications with a
warm contact convert far better than volume, and recruiters see every
application you send to their company.
