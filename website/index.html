About projectOpen sourceMIT

CareerOS is an open-source AI agent for the job search. It finds fresh roles, checks each one against your rules with quotes from the posting, and writes applications from your real experience only.

01
Discover ↓ Star on GitHub

Main goal

Get people interviews, not application counts. CareerOS reads company career pages directly, filters by rules you set, and only prepares applications it can back up with evidence from your own work.

Why it's different

Every keep or skip records the exact sentence that decided it. A code gate blocks resume lines your experience can't support, and messages are drafted for you to send. Run it on your own machine with your own API key.

How it worksFour steps

From a posting to an interview, with a person deciding at every step that matters.

04
01

Find

An hourly scan reads company hiring systems, verifies each role and keeps only those inside your rules, with quotes.

02

Score

Your model scores fit 1 to 5, requirement by requirement. Code checks every quote; under 4.0 waits for you.

03

Tailor

A resume and note built only from claims in your Career Brain. Anything it can't back up is blocked.

04

Track

Replies from your inbox move each role along. Follow-ups, referral notes and thank-yous are drafted for you to send.

Open sourceBring your own key

Clone it, add your own API key, and run the whole agent on your machine. Your resume and search history never leave it.

05
# install
$ git clone https://github.com/VishStack01/careeros && cd careeros
$ pip install -e .
# your model, your key (or put them in .env)
$ export CAREEROS_LLM=anthropic # openai, gemini, ollama
$ export ANTHROPIC_API_KEY=sk-ant-...
$ careeros llm test
# go
$ careeros init && careeros serve # http://127.0.0.1:8765
Providers

The AI steps (reading your resume, scoring fit, tailoring applications, drafting notes) call the model you choose with your key. Scanning, filtering and tracking run without any model at all, and Ollama runs everything locally for free.
