How it worksFour steps

From a posting to an interview, with a person deciding at every step that matters.

04
  1. 01

    Find

    An hourly scan reads company hiring systems, verifies each role and keeps only those inside your rules, with quotes.

  2. 02

    Score

    Your model scores fit 1 to 5, requirement by requirement. Code checks every quote, and anything under 4.0 waits for you.

  3. 03

    Tailor

    A resume and note built only from claims in your Career Brain. Anything it can't back up is blocked.

  4. 04

    Track

    Replies from your inbox move each role along. Follow-ups, referral notes and thank-yous are drafted for you to send.

Open sourceBring your own key

Clone it, add your own API key, and run the whole agent on your machine. Your resume and search history never leave it.

05
# install
$ git clone https://github.com/VishStack01/careeros && cd careeros
$ pip install -e .
# your model, your key (or put them in .env)
$ export CAREEROS_LLM=anthropic # openai, gemini, ollama
$ export ANTHROPIC_API_KEY=sk-ant-...
$ propelo llm test
# go
$ propelo init && propelo serve # http://127.0.0.1:8765
