# Weekly review

1. Funnel for the last 7 and 30 days: found → ready → applied → screen → interview → offer, split by region, source, positioning variant and whether a warm contact existed.
2. Speed: median hours from posting to submission (target under 12 for Reach and Target roles).
3. Skip mining: group skipped roles by gate. If one gate rejects most fresh, relevant roles (for example experience), tell the user and suggest the specific setting to change or the skill to build.
4. Gap map: the 10 skills most often required in kept roles that the brain has weak or no evidence for, ranked by frequency.
5. Experiment: change exactly one thing for next week (headline wording, note length, submission time window, positioning) and record the hypothesis. Report last week's experiment with its sample size; don't claim a result from a handful of applications.
6. Write the report to `reports/<date>.md` and summarise it to the user in five lines.
